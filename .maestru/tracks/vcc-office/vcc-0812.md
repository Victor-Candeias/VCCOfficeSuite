# VCC-0812 — Dashboards múltiplos

Implementar a alternância entre o dashboard clássico existente, o moderno escuro/claro e o Launcher em grelha das 26 aplicações. Preferências locais em SQLite: preferido `modern`, arranque `last`, tema `system`. Não remover os ecrãs anteriores. As operações de negócio ainda não implementadas devem permanecer desativadas.

## Critérios de aceitação

- [ ] Vistas moderno, clássico e grelha selecionáveis sem reinício.
- [ ] Definições de dashboard preferido, modo de arranque e tema guardadas em SQLite.
- [ ] Primeiro arranque abre moderno; arranques seguintes respeitam último dashboard.
- [ ] Tema `system` segue a aparência do Windows nas novas vistas.
- [ ] Ausência de dados falsos de recentes, favoritos e partilhas.
- [ ] Testes unitários, build Debug/Release e Maestru check aprovados.
